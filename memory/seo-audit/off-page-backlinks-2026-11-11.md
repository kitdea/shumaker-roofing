# Off-Page SEO & Backlink Profile Audit — shumakerroofing.com

**Date:** 2026-11-11
**Subject:** Shumaker Roofing Company (roofing contractor), Frederick, MD — https://shumakerroofing.com
**Method:** Free/public sources only. **No paid backlink index (Ahrefs, SEMrush, Moz) was used or available.**

> ⚠️ **PROMINENT CAVEAT: This is a FLOOR ESTIMATE, not a comprehensive backlink audit.** Free tools sample a fraction of the web (mostly via Common Crawl snapshots) and miss most of a real link profile — paid tools (Ahrefs/SEMrush/Moz) index tens of billions more pages. Every number below should be read as "at least this many, confirmed via free tools" — not "the total." A paid tool is recommended before making link-building budget decisions.
